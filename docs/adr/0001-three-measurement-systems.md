# Три системы измерения

Оценка хода закрывает сцену, характеристики копятся долго, прирост — два числа без потолка. Свести их в одну шкалу проще на вид, но тогда нельзя отдельно решить исход реплики, долгое свойство ученика и накопитель на главной. Оставляем три линейки и не сливаем имена шкал, даже если слова пересекаются.

## Considered Options

- Одна шкала на всё
- Две линейки: оценка хода и характеристика, без прироста
