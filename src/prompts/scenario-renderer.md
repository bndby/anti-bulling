# Scenario Renderer

Создай короткое вступление к учебной симуляции буллинга для ребёнка 10–16 лет.

Параметры:
Место: {{place}}
Тип: {{conflictType}}
Интенсивность: {{intensity}}
Персонаж: {{characterName}}
Запрос пользователя: {{userRequest}}

Верни JSON:
```json
{
  "title": "...",
  "setup": "2-4 предложения: что произошло ДО конфликта и почему ситуация возникла (от второго лица «ты»)",
  "context": "одно предложение — что происходит прямо сейчас",
  "openingLine": "первая реплика буллера",
  "bullyGoal": "..."
}
```

Без насилия, мата, сексуального контента. На русском.
Поле setup обязательно: ребёнок должен понять, что привело к конфликту.
